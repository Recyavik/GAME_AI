# Архитектура проекта

## Стек
- Node.js 20+ и npm (https://nodejs.org, LTS).
- Vite 6 — dev-сервер с горячей перезагрузкой и сборка.
- three.js — 3D (из npm, встраивается в сборку; CDN не используется — игра работает офлайн).
- vite-plugin-singlefile — вся игра в один `dist/<TEMA_N>.html` (картинки, голоса и шрифты внутри).
- sharp и ffmpeg — подготовка картинок и записей голоса (`npm run assets`).
- puppeteer-core + установленный Chrome/Edge — сквозной тест (`npm run test:e2e`).
- Python 3 — только для `tools/make_release.py` (архив выпуска).

## Структура
```
GAME_AI/
├─ package.json  vite.config.js  index.html
├─ src/
│  ├─ main.js              точка входа: шрифты, стили, start(scenario, world)
│  ├─ styles/              base.css (интерфейс), widgets.css (мини-задания, HUD, живой мир)
│  └─ engine/
│     ├─ runner.js         исполнитель сценария: титул, этапы и гибкие цели, сохранение, финал
│     ├─ core.js           рендерер, сцена, свет, тени, цикл кадра, пауза под окнами
│     ├─ camera.js         режимы follow / cine / orbit, зум, поворот (yaw)
│     ├─ player.js         ходьба: клик, WASD (относительно камеры), путь, «отлипание» от углов
│     ├─ nav.js            сетка проходимости, A*, временные препятствия (setBlock)
│     ├─ props.js          WorldBuilder (комнаты, стены, таблички, указатели на полу) и мебель F.*
│     ├─ characters.js     низкополигональные персонажи из примитивов + анимация
│     ├─ life.js           живой мир: мячи, шарики, Шустрик, доставщики, ученики, голограммы,
│     │                    камеры с рамками, телефон с уведомлениями
│     ├─ hud.js            карточка этапа, счётчики, док кнопок, метка цели, значки «?», документы
│     ├─ dialog.js         диалоги с портретами, печать текста, пробел — дальше
│     ├─ modal.js          окна, тосты, конфетти, стек окон для Esc
│     ├─ stations.js       окно станции: шаги-виджеты, карточка щита, «Выйти из задания?»
│     ├─ findings.js       прогресс: карточки, щиты, листовки, факты, достижения, очки, блокнот
│     ├─ finale.js         финал, «Было — стало», тест, «Закрыть игру»
│     ├─ eyes.js           зарядка для глаз (напоминание через 20 минут, таймер на кнопке)
│     ├─ save.js           «Продолжить» после перезагрузки (localStorage; без него — новая игра)
│     ├─ sound.js          WebAudio: звуки интерфейса, фоновый гул, записи голоса с шумом
│     ├─ speech.js         запасная озвучка speechSynthesis
│     ├─ title.js          титульный экран, выбор героя, «Продолжить»
│     ├─ util.js           h(), rich() (разметка и формы рода {а}/{м|ж}), shuffle и т. п.
│     └─ widgets/          мини-задания станций (index.js — реестр), kit.js — общие детали
├─ games/
│  └─ TEMA_1/
│     ├─ scenario.js       ДАННЫЕ: герои, персонажи, карточки, щиты, листовки, этапы, финал, тест
│     ├─ world.js          мир: комнаты, мебель, точки станций, NPC, живой мир, действия (шлюз)
│     ├─ images.js         подключение картинок (WebP) группами
│     ├─ voice.js          подключение записей голоса (MP3)
│     └─ assets/           готовые веб-версии картинок и голосов
├─ tools/
│  ├─ run.mjs              dev / build / build --all / list
│  ├─ prep_assets.mjs      исходники → WebP и MP3 (размеры, обрезка, нарезка шумов)
│  ├─ check.mjs            проверка данных сценария без браузера
│  ├─ e2e.mjs              прохождение игры в браузере (автопилот + решение станций)
│  └─ make_release.py      архив выпуска releases/ai-quest-NNN.zip
└─ TEMA_1.html             готовая игра (копия dist/TEMA_1.html)
```

## Команды
- `npm run dev -- TEMA_N` — dev-сервер с горячей перезагрузкой.
- `npm run build -- TEMA_N` — `dist/TEMA_N.html` и копия `TEMA_N.html` в корне.
- `npm run assets -- <папка исходников> games/TEMA_N/assets` — подготовить ассеты.
- `npm run check` — проверить данные; `npm run test:e2e -- dist/TEMA_N.html [--hero 2] [--resume N]` — пройти игру.
- `npm test` — проверка данных + сборка всех игр + прохождение TEMA_1.
- Отладка: открыть игру с `#debug` в адресе — в `window.__dbg` будут player, rig, nav, W.

## Сценарий (games/<TEMA_N>/scenario.js) — только данные
- `meta` — номер занятия, классы, название, завязка, тема, акцент.
- `heroes` — выбираемые герои (портрет, внешность, точки лица для фото на пропуск).
- `cast` — персонажи: имя, портрет, внешность (look).
- `cards`, `shields`, `memo`, `rumors`, `achievements`, `ranks` — находки, правила, листовки, награды.
- `eyes`, `life`, `warmup` — зарядка для глаз, живой мир, разминка.
- `stages` — этапы: `id`, `requires`, `title`, `task`, `goal` (точка мира), `place` (расстановка NPC),
  `flow` — шаги по порядку: `{ say }`, `{ station: { kind, widget|steps, card, shield } }`,
  `{ goal }`, `{ place }`, `{ act }`.
- `finale`, `quiz` — выводы и итоговый тест.

Варианты ответов: `{ text, ok, why }` — по 4, перемешиваются; `why` у неверного объясняет,
чем плох именно этот выбор. `npm run check` проверяет число вариантов, длину верного,
картинки, звуки и ссылки между этапами, персонажами и точками мира.

## Мир (games/<TEMA_N>/world.js)
`world(W, F)`: `W.room`, `W.item(fn, x, z, rot, { block })`, `W.box/cyl/ball/cone`, `W.picture`,
`W.sign`, `W.floorArrow`, `W.onWall` (предмет прячется со стеной), `W.point` (станции),
`W.spot` (листовки), `W.npc` (NPC и их запасные места `id@…`), `W.life` (живой мир),
`W.actions` (действия сценария), `W.exit` (выход из школы → «Выйти из игры?»).
Анимированные предметы кладут `g.userData.tick` — мир вызывает его каждый кадр.

## Офлайн и вес
- Шрифты — из `@fontsource`, встраиваются. Никаких запросов наружу (это проверяет e2e).
- Картинки — WebP, голоса — MP3 моно 48 кбит/с; картинки темы — ориентир до 2–3 МБ.

## Производительность (школьные ПК)
- pixelRatio ≤ 1.5, одна тень от направленного света, сцена на паузе под окнами.
- Статичная геометрия объединяется (`W.bake`), анимированное — в `W.dynamic`.
